# AccessMap — AI-powered accessibility map (MVP)

AccessMap helps people explore places and understand reported wheelchair-accessibility details. This repository is a runnable starter prototype built with:
- Frontend: HTML, CSS, vanilla JavaScript, Leaflet/OpenStreetMap
- Backend: Java 21+ / Spring Boot 3, Maven
- Database: PostgreSQL (optional for demo mode; see below)

> Important: This is a prototype. Accessibility reports are community-provided and may be incomplete or outdated. Do not treat unknown information as confirmation that a place is accessible.

## Run locally (quick demo)

### 1. Start the backend
Requirements: Java 21+ and Maven 3.9+.

```bash
cd backend
mvn spring-boot:run
```

The API starts at `http://localhost:8080`. The starter backend stores sample/demo data in memory, so you can try it without PostgreSQL.

If Maven is not installed, install it or use a Maven wrapper generated by your IDE. Java 26 should work with the Spring Boot 3.5 line, but Java 21 or 25 LTS is a safer team baseline.

### 2. Start the frontend
Open a second terminal from the repository root:

```bash
cd frontend
python3 -m http.server 5500
```

Open `http://localhost:5500`.

The frontend calls `http://localhost:8080/api/v1/places`. If the backend is not running, the page shows a clear message and demo cards still render.

## PostgreSQL (optional next step)

The current starter uses in-memory demo data to make first run easy. To add PostgreSQL, create a database, configure `spring.datasource.*` in `backend/src/main/resources/application.properties`, add a Spring Data JPA repository and entity mappings, then replace the in-memory service. The schema proposal is in `database/schema.sql`.

## OpenAI integration (optional)

The AI endpoint currently returns a safe, evidence-grounded demo answer and does not require an API key. If you integrate a model later, call it from the backend only and store the key in an environment variable such as `OPENAI_API_KEY`. Never commit API keys to Git.

## API endpoints

- `GET /api/v1/health`
- `GET /api/v1/places`
- `GET /api/v1/places/{id}`
- `GET /api/v1/places/{id}/reports`
- `POST /api/v1/places/{id}/reports`
- `POST /api/v1/ai/ask`
